{%- comment -%} Outputs the URL of a given page of the post index. Page 1 lives at the index itself (/posts/), later pages at paginate_path (/posts/page2/). params: num - 1-based page number Emits a bare URL, so call it inside an attribute: href="{% include ... %}" {%- endcomment -%} {%- assign index_path = site.paginate_path | split: "page:num" | first -%} {%- if include.num and include.num > 1 -%} {{- site.paginate_path | replace: ":num", include.num | relative_url -}} {%- else -%} {{- index_path | relative_url -}} {%- endif -%}
